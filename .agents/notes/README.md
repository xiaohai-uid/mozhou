# Agent Notes（决策记录）

> 给 AI 会话用的轻量决策记录：记"为什么这样做、放弃了什么、怎么验证的"。
> 它不替代现有系统，只补"AI 当时为什么这么选"这一块。

## 和现有记录的分工

| 内容 | 记在哪 |
|---|---|
| AI 会话中的架构取舍、被拒绝的方案、新约定的由来 | `.agents/notes/`（这里） |
| 正式架构决策 | `docs/adr/`（按需懒创建） |
| 工单级实现细节、试错过程 | `.scratch/<project>/issues/NN-*.md` |
| 技术预研结论 | `docs/spikes/` |
| 个人项目笔记 | Obsidian `10_Projects/墨舟.md` |

一个事实只记一处，写之前先想"这事该进哪个家"。

## 什么时候写

- 做了架构 / 契约 / 目录结构层面的取舍
- 拒绝了一个看似合理的方案（后人一定会再问"为什么不用 X"）
- 定了一条以后 AI 都要遵守的新约定
- 踩了坑，且验证方式不显而易见

## 什么时候不写

- 纯机械改动、局部 UI 调整（走工单记录）
- 一次性的调试过程（修完即弃）

## 规范

- 文件名：`YYYY-MM-DD-<slug>.md`，slug 用英文短横线
- 一份 note 只记一个决策，不超过 800 字，能短则短
- 用 `_template.md` 起草
- 状态流转：`proposed` → 落地后移到 `implemented/` → 被推翻后移到 `archived/`
- `archived/` 里的 note 冻结，不再修改（要反驳就写新 note 链接回去）
