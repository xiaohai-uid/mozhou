# Contracts: 采纳端点与出站行为的可观察契约增量

**Feature**: `005-author-data-boundary-hardening` | **Date**: 2026-10-12

> 契约全集仍以 `.scratch/mozhou-mvp/contracts/api-contract.md`（已实现端点以后端发射端 + 契约测试为准）为准。本文件只记录**本轮引起的可观察增量**，不复制既有契约全文。

## C1 `POST /api/draft.accept` — 响应与拒绝语义

| 场景 | 本轮之前 | 本轮之后 | 依据 |
|---|---|---|---|
| 同书并发写入 | 不与其他正文写入互斥 | 与保存/备份等共用书稿写锁；被占用排队，超时返回 409 `BOOK_WRITE_BUSY` | FR-001 |
| 同请求重放（同操作标识 + 同摘要） | 返回 `alreadyApplied: true` | 不变；且**补齐**结果记录与任务关联后才返回 | FR-005 |
| 同候选同幂等键、但换操作标识 | 走 done 回放返回 `alreadyApplied: true`（**旁路**） | 409 `IDENTITY_MISMATCH`（副作用前） | FR-002 |
| 主体不匹配、请求省略操作标识（意图已存原身份） | 返回 `alreadyApplied: true`（**旁路**） | 409 `IDENTITY_MISMATCH`（副作用前） | FR-002/FR-004 |
| 意图缺原身份（历史记录）+ 请求带操作标识 | 返回 `alreadyApplied: true`（**旁路**） | 409 `IDENTITY_MISMATCH` | FR-004 |
| 正文已落、结果未记录时中断后重试 | 返回 `alreadyApplied: true`，**结果查不到** | 返回 `alreadyApplied: true`，结果与任务关联**已补齐** | FR-005 |
| 老客户端（从不携带操作标识）的既有采纳与回放 | 正常 | **不变**（意图无原身份 + 请求无标识 ⇒ 兼容路径） | FR-003/FR-004 |

**新增错误码**: `IDENTITY_MISMATCH`（沿用既有 `AcceptConflictError` 的 409 通道，不新增 HTTP 状态码）。

**前端契约不变**: 工作台每次采纳携带 `operationId = op_accept_<candidateId>` 与 `idempotencyKey = ui_accept_<candidateId>`，重试时两者一致，故始终走合法回放路径。

## C2 `POST /api/draft.cancel` — 并发语义

- **本轮变更**: 取消与采纳/保存共用同一书稿写锁（此前无互斥），被占用时按同一规则返回 409 `BOOK_WRITE_BUSY`。响应体形状不变。

## C3 持久格式契约（见 `data-model.md` E1/E5/E6）

- 采纳意图：`schemaVersion` 写入 2、读取接受 1/2；新增可选 `operation` 块。**读取端向后兼容；写入端单向升级。**
- 事件账本：恢复入口新增物理完整性前置（半行即不可恢复）。**发布与审计读的既有格式不变。**
- 草稿运行态：新增候选私有派生文件，保持 `stateVersion: 1`；章文件继续表示当前认领者。旧任务不得通过取消、完成、失败或备用 attempt 覆盖新任务指针。生产生成入口按本次候选读取；旧章文件仅身份相符时回退。

## C4 出站行为契约（对上游可观察）

| 维度 | 契约 |
|---|---|
| 连接目标 | 连接固定到已验证的解析地址；请求仍以**原域名**作为 Host 与证书校验对象 |
| 压缩协商 | 声明与既有实现一致的协商集合；响应按声明的编码解码，流式与整体读取一致 |
| 未支持编码 | 显式失败（不把原始字节当正文） |
| 重定向 | 模型与检索不自动跟随；爬虫沿用手动逐跳校验，跨 origin 移除凭据头，同 origin 保留 |
| 取消 | 启动前/解析期间取消 ⇒ 零请求；读取期间取消 ⇒ 错误分类为「已取消」；非取消的远端断开保持网络失败分类 |
| 时限与清理 | 时限涵盖 DNS 等待、连接和正文；结束等待不等于取消 OS DNS。响应、解压器和请求共同释放 |
| 环境代理 | 地址绑定请求使用独立直连，不复用全局环境代理或旧连接；依赖代理的真实提供商连通性未验证 |
| 部署者授权本机端点 | 不参与公网地址校验；既有授权行为不变 |
| 私网/环回/保留解析 | 整体拒绝，零出站请求 |

- 未变更作者数据（正文/正典/清单）的既有契约。
