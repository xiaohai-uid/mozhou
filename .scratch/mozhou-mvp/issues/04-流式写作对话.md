# 04 — 流式写作对话

**What to build:** 作者在浏览器里与 AI 对话写作：输入消息发送后，回复以打字机流式效果逐字出现；对话按会话持久化；可切换模型（免费模型走 one-api）。这是第一个端到端可演示切片——"在墨舟里开始写作"。

**Blocked by:** 02 邮箱认证, 03 管线引擎核心

**Status:** ready-for-agent

- [ ] 对话页（深色编辑器风）：消息列表 + 输入框（Enter 发送，Shift+Enter 换行）
- [ ] 流式输出（SSE）打字机效果
- [ ] 会话持久化（messages 表），刷新不丢
- [ ] 模型选择器（DeepSeek/Qwen，经 one-api）
- [ ] 每次调用经管线引擎（记账生效）
- [ ] 新会话/会话历史切换
