# 05.5 — DB 迁移追踪修复（__drizzle_migrations）

**What to build:** 修复数据库迁移追踪缺失。库内 `drizzle.__drizzle_migrations` 跟踪表与 drizzle-kit 期望状态脱节（0003 曾为手动应用、且出现过重复记录），导致下次 `drizzle-kit migrate` 可能全量重放 0000-0002 撞已存在的 users 表。

**Status:** done（2026-08-10）

**Root cause:** 早期迁移（0000-0002）由旧流程写入跟踪表；0003 生成后首次 migrate 时因与残留旧表冲突未完整落记录，后又经手动 psql 应用（无跟踪记录）→ 跟踪表出现重复行且 0003 hash 来源不一致。

## 修复步骤
1. 确认 drizzle 机制：hash = `sha256(SQL 文件全文)`（`drizzle-orm/migrator.js` `readMigrationFiles`）；判断逻辑 = 取跟踪表**最后一条** `created_at`，`< folderMillis` 才重放（`pg-core/dialect.js:62`）
2. 重建跟踪表记录：按 journal 逐条以官方 hash 写入
3. 去重：`DELETE ... WHERE id NOT IN (SELECT min(id) GROUP BY hash)` → 4 条
4. 校验：表内 hash 与 `sha256(文件全文)` 逐条比对全部一致
