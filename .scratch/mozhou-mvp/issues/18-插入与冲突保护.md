# 18 — 插入与冲突保护（DocumentConflict/CandidateStale 语义）

**What to build:** 插入端点（快照比对 + force + 409 ContentChanged）+ 对话面板插入/部分采纳/冲突确认接真实。

**Blocked by:** 16（正文）+ 17（消息）

**Status:** ready-for-agent

**契约（21-章节级续写契约.md 第 2/3 节）：**
- `POST /api/v1/novels/{novelId}/chapters/{chapterId}/messages/{messageId}/insert`
  - body `{ content: string, force?: boolean }`（content=实际插入文本，客户端可删改 = 部分采纳）
  - 200 `{ chapter: { content, updatedAt }, message: { inserted: true } }`
  - 409 `{ error: "正文已变化，这条回复基于旧正文", code: "ContentChanged" }`（snapshot≠当前 content 且非 force）
  - 400（消息不存在/非 assistant/已插入/content 空）
- 插入 = 正文末尾追加；消息标记 inserted

- [ ] 服务层：insertChapterMessage（快照比对 → 追加 → 标记；归属校验）
- [ ] 路由：POST insert（409/force/400 路径）
- [ ] 契约测试：插入成功（正文追加 + inserted）/ 正文变化 → 409 / force 重发成功 / 已插入重复 400 / 非 assistant 400 / 越权 404
- [ ] 对话面板接真实：插入按钮（提交可删改文本）/ 409 → 冲突确认条（仍要插入=force 重发 / 取消）/ 已插入标记
- [ ] 停止后插入（stopped 消息同路径）

**验收：** 插入真实追加正文；生成中改正文后插入 → 冲突确认 → force 成功；已插入消息标记持久（刷新仍在）。
