## 1. Interaction Contract（交互语义，UI 已冻结）

| 用户动作 | 契约行为 | 失败语义 |
|---|---|---|
| 打开章节页 | 载入章节元信息 + 正文 + 对话消息历史 + 我的技能 | 404（他人/不存在章节）；401 |
| 编辑正文 | 本地即时生效；防抖 2s 自动保存（PATCH content）；显式"保存"按钮同端点 | 保存失败 → 状态"保存失败"+ 人性化提示，正文不丢（本地态） |
| 对话发送 | user 消息立即上屏（落库）→ AI 流式回复（SSE）→ 完成后消息落库（技能快照 + 正文快照） | error 事件携带 code → 人性化面板 |
| 停止回复 | 客户端断开 SSE；服务端将 AI 消息标记 `stopped`（保留已生成部分） | — |
| 插入正文 | 客户端提交要插入的文本（可删改 = 部分采纳）；服务端比对快照 → 一致：正文末尾追加 + 消息标记 inserted；不一致：409 确认态 → 用户确认后 force 重发 | 409（正文已变化）；400（非 assistant/已插入/空） |
| 忽略回复 | 客户端收起操作区（消息留存，无服务端动作） | — |
| 技能选择 | 技能胶囊 = 场景技能（内置，按章节状态切换）+ 我的技能（已安装）；随消息发送 `skills[]` | — |
| 空章节起笔 | "让 AI 起笔"= 触发内置「章节起笔」技能发送 | 与对话发送一致 |
| 错误展示 | 客户端按 error code 映射人性化（标题+怎么办+动作：retry/reconfigure/switch_model） | — |

## 2. Application/API Contract

```typescript
// ── 正文读写（chapters 扩展 content；保存 = PATCH content，自动/显式同端点） ──
// GET  /api/v1/novels/{novelId}/chapters/{chapterId}
interface ChapterDetail { id: number; ch: string; title: string; content: string; status: "draft"|"final"; updatedAt: string }
// PATCH /api/v1/novels/{novelId}/chapters/{chapterId}   body: { content?: string; title?: string; status?: "draft"|"final" }
// 200 { chapter: ChapterDetail }；404（越权/不存在）

// ── 章节对话（对话留存 Q1：消息随章节持久化） ──
// GET  /api/v1/novels/{novelId}/chapters/{chapterId}/messages
interface ChapterMessage {
  id: number; role: "user"|"assistant"; content: string;
  skills: string[];          // 生效技能快照（仅 assistant）
  snapshot: string;          // 生成时正文快照（冲突检测基准，仅 assistant）
  status: "done"|"stopped"|"error"; inserted: boolean; createdAt: string;
}
interface MessageListResponse { messages: ChapterMessage[] }

// POST /api/v1/novels/{novelId}/chapters/{chapterId}/chat   （SSE，text/event-stream）
interface ChapterChatRequest {
  content: string;                 // 用户输入（上限 4000 字）
  model?: "deepseek-v4-flash" | "glm-4.5-flash";
  styleId?: number | null;         // 风格库引用（复用工单 15 注入）
  skills?: string[];               // 技能名列表（内置场景技能 + 我的技能）
}
// SSE 事件流（start → delta* → done | error；客户端断开 = 停止）：
//   { type: "start";  sessionId?: never; messageId: number }        // AI 消息已建（后续落库）
//   { type: "delta";  text: string }
//   { type: "done";   messageId: number; inserted: false }          // 完成落库（含 skills/snapshot）
//   { type: "error";  code: string; message: string }               // code 供人性化映射
// 服务端注入顺序（system）：正文参考（末尾 3000 字）→ RAG 设定（novelId）→ 风格（styleId）→ 技能（skills）

// ── 插入（部分采纳 = 客户端可删改后提交；冲突保护 = 快照比对） ──
// POST /api/v1/novels/{novelId}/chapters/{chapterId}/messages/{messageId}/insert
interface InsertRequest { content: string; force?: boolean }   // content = 实际插入文本（可删改）
// 200 { chapter: { content, updatedAt }, message: { inserted: true } }
// 409 { error: "正文已变化，这条回复基于旧正文", code: "ContentChanged" }（snapshot≠当前 content 且非 force）
// 400（消息不存在/非 assistant/已插入/content 空）
```

## 3. Domain Model

- **章节正文**：Chapter.content（章节实体扩展；保存幂等覆盖，用户编辑不设版本号——冲突保护只在插入环节）
- **章节对话消息**：ChapterMessage（user/assistant；assistant 带 skills 快照 + snapshot 快照 + status + inserted）
- **插入动作**：Insertion = 文本 + 生成快照比对 + force 语义（ContentChanged 冲突）
- **场景技能**：SceneSkill = 平台内置常量（章节续写/章节起笔，按章节空态切换），注入与普通技能同构
- **错误码**：AiNoApiKey / AiRateLimited / AiServerError / AiTimeout / AiNetworkError / AiInvalidResponse / AiCancelled / ContentChanged / DiskWriteFailed（humanize 映射）

## 4. Persistence Model（Contract Frozen 定案，E 节未决落地）

```sql
-- migration 0011：chapters 加 content
ALTER TABLE chapters ADD COLUMN content text NOT NULL DEFAULT '';

-- 新表 chapter_messages（章节对话留存）
CREATE TABLE chapter_messages (
  id serial PRIMARY KEY,
  chapter_id integer NOT NULL REFERENCES chapters(id) ON DELETE CASCADE,
  user_id integer NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  role text NOT NULL,                -- user | assistant
  content text NOT NULL,
  skills jsonb NOT NULL DEFAULT '[]',      -- 生效技能快照（assistant）
  snapshot text NOT NULL DEFAULT '',       -- 生成时正文快照（冲突检测基准）
  status text NOT NULL DEFAULT 'done',     -- done | stopped | error
  inserted boolean NOT NULL DEFAULT false,
  created_at timestamp NOT NULL DEFAULT now()
);
CREATE INDEX chapter_messages_chapter_idx ON chapter_messages(chapter_id, id);
```
