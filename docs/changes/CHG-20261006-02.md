## 2. 实现内容

### 2.1 TipTap/ProseMirror AST 编辑器（editor-ast 补缺）

- **依赖**：`pnpm add @tiptap/react @tiptap/core @tiptap/pm @tiptap/starter-kit` → **3.31.4**（`apps/web/package.json:23-26`、pnpm-lock.yaml 158 处命中、`node -e require.resolve` 实证）。安装需按仓库 preinstall 守卫（`scripts/check-install-env.mjs`）设 `ONNXRUNTIME_NODE_INSTALL_CUDA=skip`。
- **`prose-ast.ts`（新）**：纯文本 ↔ PM 行模型唯一桥梁。round-trip 无损不变量 `proseLinesToText(textToProseLines(t)) === t`；PM 位置映射（paragraph size=2+len、sceneBreak atom size=1）；`planRangeReplacement` 字符串切片语义规划（含 openStart/openEnd Slice 开放度——边界落段中间 ⇒ 与现有段落拼接，否则块级替换劈开段落）。
- **`NovelEditorCanvas.tsx`（重写，348→381 行）**：TipTap `useEditor` + StarterKit（仅 document/paragraph/text/hardBreak/undoRedo/dropcursor/gapcursor，其余 15 项富文本扩展显式关闭）+ `SceneBreak` 自定义 atom 节点 + `ChineseIndent` 扩展（Enter 两全角缩进，`view.composing` 时不拦截——中文 IME 优先）。对外契约不变：`value`/`onChange` 仍是正文纯文本字符串；新增 imperative handle（`replaceRange`（open Slice 局部替换，可撤销）/`setSelection`/`undo`）。Slash（scene=真场景节点）、Bubble、一键排版、placeholder 全保留。
- **`customNodes.ts`（重写）**：`SceneBreak` PM 节点（marker 存原始行文本，round-trip 无损）+ `blocksFromText` 结构标注；删除无引用死函数 `parseTextToBlocks`/`serializeBlocksToText`（grep 全仓零引用，被 `blocksFromText` 取代）。
- **projection**：`workbenchStorage.ts` 新增 `loadEditorProjection`/`saveEditorProjection`（键 `mozhou.editor.projection.<ch_key>`，绑定书身份同 draft cache 纪律）；`ProseEditorPanel.handleChange` 随正文回写（场景块等结构存本地投影，不进 Chapter body）。
- **IME/验收对应**：中文输入走 PM 原生 composition（无装饰性按键拦截；Enter 缩进 shortcut 显式让路 IME）；旧 textarea 草稿无损打开由 round-trip 不变量 + 测试锚定。

### 2.2 `/api/prose.edit.stream` 契约（inline-ai 补缺）

- **`proseEditRoutes.ts`（新，217 行）**：单契约承载四预设（sensory_expansion/deslop_sharpen/dialogue_polish/plot_twist）+ custom（`customInstruction` 必填）。入参 `root+chapterIndex+action+selectedText+selectionRange+surroundingContext?+customInstruction?`，长度护栏（20k/4k/2k）。NDJSON 帧：`start{candidateId,action,provider}` → `delta{text}*` → `done{chars}` / `error{error}`。**输出只产候选流，零写盘**（契约测试以目录快照断言）。
- **Provider 接缝（与 draft.stream 单缝同源）**：mock 判据复用 `pipelineRoutes.isMockDraftProviderMode`（加 export 缝，禁止复制判据）；`MOZHOU_DRAFT_PROVIDER=mock` 回吐选区原文三段切块（不伪造改写）、`mock-empty` 走 `emptyDraftStream`（空流守卫 → error 帧，不给「完成的空候选」）；真实分支 `resolveGenerationTarget`（注册表→BYOK 单缝）+ `streamOpenAiChat`（内置 HTTPS-only + 私有/环回地址 SSRF 门——服务端 URL 约束由既有层满足）；仅 `no_provider_configured` 以 PROVIDER_UNAVAILABLE 前置闸收口（与 draft.stream 同语义），配了但解析不出进 NDJSON error 帧。
- **登记与装配**：`routePolicies.ts` `/api/prose.edit.stream: 'book'`；`api.ts` `.use(proseEditRoutes)`（pipelineRoutes 之后）。
- **`draftStreamEmulation.ts`**：新增 `mockProseEditStream`（非重叠切片纪律与 `mockDraftStream` 一致；回吐选区原文，Accept 后正文不变——mock 诚实语义）。

### 2.3 链路接线（选区 → Candidate → Diff → Accept/Reject → AST 局部替换 → Active Draft → revision-safe save）

- **`ProseEditorPanel.tsx`（354→511 行）**：`handleSelectionAction` 从诚实不可用桩改为真实调用——`fetch('/api/prose.edit.stream')` NDJSON 流消费（AbortController，切书/切章/卸载中止），`pendingEdit` 承载候选快照；**Accept 三守卫**：①选区不漂移（`text.slice(from,to) === original` 逐字校验，失效即拒绝并提示，不写错位置）②`canvasRef.replaceRange` AST 局部替换（PM transaction，可撤销）③Accept ≠ 落盘（不触发 `/api/chapter.prose.save`，落盘走既有「落为当前章草稿」revision-safe 入口）；Reject 一字不改；AI 失败（error 帧/HTTP 异常）诚实 notice、正文不动。
- **`InlineDiffViewer.tsx`（孤文件 → 接线）**：扩展 `loading`（流式中按钮禁用）与 `quality`（FR-3.3 采纳前质量遥测：`runDeAiDiagnostics` + 4-gram 复读，绿=纯净/黄=待复核徽标）props。
- 原有冲突保护/定稿边界/防误关丢稿守卫/候选候选面全部未动（测试回归锚定）。
