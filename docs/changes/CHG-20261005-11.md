## 观察基线

- `executeChapterReview` 同时装配质量/机械审查、持久化报告、收割/吸收及推进会话；语义提供方缺省 `unknown → refused`。
- Web 审查入口 `semanticReviewer` 字段硬编码为 `'unavailable'`，未接通任何真实语义提供方。
- 无超时、无取消：`Promise` 挂起时宿主无限等待，无终止与清理路径。
- `apps/web/shared/reviewCapability.schema.ts`（CHG-10 新增）为自持 JSON Schema 与手写解释器，含 `expectedVerdict` 重算与机械结论重算。

## 目标行为

1. 契约简化：移除 `expectedVerdict`、机械总结论重算与业务规则仲裁；业务一致性归一质量引擎。
2. 生产接线：宿主负责正文读取、编译凭证核验、报告落盘、金句收割、反例吸收与会话推进；能力执行端只接收正文快照、策略与明确配置；保持既有 HTTP 返回兼容。
3. 接通真实语义审查提供方：配置存在即可用，缺失明确 `unavailable`，不伪造 PASS。
4. 超时与取消：JSON 请求支持受宿主限制的 `timeoutMs`；`AbortSignal` 传递至真实网络调用；进程树可强制终止。
5. 迟到保护：超时/取消/失败后的迟到结果不再落盘、收割、吸收或推进会话。
