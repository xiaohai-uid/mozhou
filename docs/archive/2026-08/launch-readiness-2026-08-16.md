## 明天上架前的硬阻断

### P0：必须二选一

1. 官网如果要承担“付费开通会员”，当前支付按钮仍是“暂未开放”，不能对外承诺已可购买。要么先不上会员销售入口，要么完成支付、回调、开通、退款/失败和账号状态 smoke。
2. 官网如果只承担下载和付费，当前仓库仍缺少已验收的桌面安装包、下载入口、授权/激活、更新和付费订单闭环；不能把当前 Web 工作台直接说成已经完成的桌面商品。
3. 生产环境必须用真实模型、真实数据库和真实迁移做一次注册 → 创建作品 → 第一章 → 生成反馈 → 候选确认 → 保存 → 刷新恢复的完整 smoke。单元测试通过不等于这条链线上可用。
4. 所有仍显示“界面示意 / 暂未开放 / 需要配置”的入口，必须在发布版本中保留明确标签或从导航移除，不能让用户误以为已经完成。

### P1：可在首发后补，但必须明确边界

- 书架章节正文抓取：当前只收录元数据；不得展示假章节。
- 榜单：当前为番茄官方榜源，其他平台检索已接入书源搜索，不等于多平台榜单。
- WebDAV：配置和单向推送路径存在，但没有真实凭据完成断网、重试、恢复和冲突 smoke。
- 封面：`/api/v1/story/cover` 仍是 `CONFIGURATION_REQUIRED`，没有真实图片模型和资产管理闭环。
- 技能目前是带契约的写作链注入，不是 OpenWrite/oh-story 那种完整工具调用、文件权限和多 Agent 执行器。
