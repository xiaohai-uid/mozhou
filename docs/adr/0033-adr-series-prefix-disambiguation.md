# 0033. ADR 双系列加前缀消歧，第三系列不可恢复

`docs/adr/` 曾有两组互不相干的决策共用 `0001`–`0007` 编号：一组英文标题（内核线），一组中文标题（应用线）。因此任何一句「ADR-0006」都是歧义的，而 `A-0006` 正文里正引用着两个这样的编号。

**裁决**：歧义写进标识符本身。英文系列加 `K-` 前缀，中文系列加 `A-` 前缀，`0008`–`0030` 未曾歧义故保持原样（最小改动）。引用时必须写全前缀。

## 关于丢失的第三系列

`A-0006` 第 12–13 行引用了「ADR-0002 Skill 运行时与正式写作链」与「ADR-0003 墨舟工作台采用 A 版双栏写作台」。**这两个文件不存在于本仓，也从未存在于本仓的 git 历史**——`git log --all --diff-filter=D -- docs/adr/*` 显示本仓只删过 1 个 ADR 文件（`0021-context-receipt-physical-storage-independent-canon-stream.md`），且与二者无关。

结论：第三系列不是被合并覆盖，而是**从未随合并进入本仓**，它留在内核线的另一个仓库里。**判定为不可恢复**，如实记录，不做推测性补写。`L-` 号段为其保留位置，若将来找回原件再启用。
